How to get a Bluesky app password

An app password lets a tool sign in to your account with limited access. It cannot change your password or email or delete your account, and you can revoke it at any time. Never enter your main password into a third-party tool.

  1. Open Bluesky at bsky.app or in the mobile app, and sign in.
  2. Go to Settings → Privacy and security → App passwords. On the web you can go straight there: bsky.app/settings/app-passwords.
  3. Select Add App Password.
  4. Enter a name you will recognize later, such as Stale Follows. Leave Allow access to your direct messages unchecked. This tool doesn’t need it.
  5. Select Next. Bluesky shows a password in the form xxxx-xxxx-xxxx-xxxx. Copy it now, because it is shown only once.
  6. Paste it into the App password field here along with your handle, then select Analyze follows.

When you’re done, go back to Settings → Privacy and security → App passwords and delete it to revoke access.

Where your app password goes

  • Not to GitHub. This site is a set of static files served by GitHub Pages. There is no server behind it, so your app password is never sent to or stored on GitHub Pages.
  • Only in your browser. The password is used once to sign in and is then cleared from the form. The session Bluesky returns is kept in this tab’s memory only, and is never saved to cookies or local storage. Closing or reloading the tab discards it.
  • Sent only to Bluesky. Your browser sends the password directly to your Bluesky account server (bsky.social, or your own PDS if you self-host). Sign out also ends the session on Bluesky.
  • App passwords only. The form rejects anything that isn’t in app-password format, so your main password can’t be sent by mistake.

Public profile and activity data is read from Bluesky’s public API and each account’s own server, without your password. You can review the full source code.

How activity is measured

Bluesky doesn’t publish when someone last logged in, so this tool uses the most recent public activity instead.

  • Last post: the account’s newest post, reply or repost.
  • Last active: the newest change of any kind to the account’s data, including posts, likes, reposts, follows, blocks and profile edits. This catches people who read and like but rarely post. It is looked up for accounts that haven’t posted in the last 30 days; for everyone else it equals their last post.
  • Gone: follows that point at deleted, deactivated or suspended accounts. They still count toward your following total.

Someone who only reads, and never likes, reposts or follows, will look inactive. Set Measured by to Posts only to judge by posting alone.

Unfollowing

Sign in with an app password, then choose Select all stale & gone under the summary. That selects every account past your threshold plus any deleted or deactivated ones. Uncheck anyone you want to keep, then choose Unfollow in the bar at the bottom of the screen and confirm. You can also tick accounts one by one.

Unfollowing deletes your follow records, which is the same as selecting Unfollow in the Bluesky app. It can’t be undone from here, so use Export CSV first if you might want the list later.
